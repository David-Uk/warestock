Postman Collection

Import the Postman collection from docs/warestock-api.postman_collection.json for pre-configured API requests.

Import instructions:

  1. Open Postman
  2. Click "Import" button
  3. Select the warestock-api.postman_collection.json file
  4. Set the base_url variable to http://localhost:8000
